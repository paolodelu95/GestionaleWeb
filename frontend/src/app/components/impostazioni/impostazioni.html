Modalità di invio

Scegli come inviare le email dei documenti.

Client integrato (SMTP) L'invio avviene dal server con le credenziali SMTP configurate qui sotto. Supporta HTML e allegati.
App mail del dispositivo Apre il client mail predefinito (Mail.app / Outlook desktop / app mobile). Richiede che il sistema abbia un client mail vero come default — su molti Mac il default è un browser, in quel caso scegli una delle opzioni webmail qui sotto.
Gmail (web) Apre il composer di Gmail in una nuova scheda con destinatario, oggetto e testo precompilati. Funziona sempre se sei loggato a Gmail.
Outlook (web) Apre il composer di Outlook web in una nuova scheda. Per chi usa Microsoft 365 / Outlook.com.

Funzionalità opzionali

Riordino automatico magazzino

Crea automaticamente un ordine fornitore quando la quantità di un prodotto scende sotto la soglia minima (richiede: fornitore preferito impostato sul prodotto).

Multi-utente

Abilita la gestione di più utenti con ruoli diversi (Admin, Commerciale, Magazziniere, Contabile, Operatore). Gestisci gli utenti nel tab "Utenti".

Numerazione documenti

Numerazione annuale

Se attiva: 2025/0001. Se disattiva: numerazione progressiva semplice 0001.

Blocca i documenti salvati

Se attivo, riaprendo un documento già salvato i campi sono bloccati (icona lucchetto in alto). Per modificare, basta cliccare il lucchetto per sbloccare. Protegge da modifiche accidentali ai documenti fiscali emessi.
